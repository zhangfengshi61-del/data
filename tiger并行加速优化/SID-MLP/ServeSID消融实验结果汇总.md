# ServeSID 消融实验结果汇总

> 消融臂定义(均在 base digit 蒸馏之上叠加):
> - **HServe only**:统一服务 KL(serve_kl=4)
> - **DA-CDRS only**:pair 锚 + DA-CDRS(pair_w=1, da_w=31.42, counterfactual)
> - **d4-only KL**:第 4 位候选列表 KL(list_kl=4)
> - **HServe + plain pair**:serve_kl=4 + pair_w=1
> - **HServe + attribution-off**:serve_kl=4 + pair_w=1 + da_w=31.42,da_mode=uniform(归因关闭对照)
> 评估:beam=50 约束解码;Jac@K 为与教师 top-K 的 Jaccard。

## 结论

1. **每个臂都有效**:三学生三数据集上,所有消融臂的 NDCG@10 均不低于 base KD,说明 ServeSID 的三个组件各有贡献。
2. **HServe 是最大单项**:HServe only 在多数配置下贡献最大,与层级蒸馏难度不均衡的动机一致。
3. **pair 与 DA-CDRS 在 HServe 之上仍能再涨**:HServe+pair / HServe+attribution-off 通常 ≥ HServe only。
4. **归因机制有效**:attribution-off(uniform)多数情况下低于 counterfactual 归因。
5. 学生越弱(CNN)消融臂增益越大,与主结果一致。
