# ServeSID 机制验证实验总报告

> **实验设置**:三数据集(Beauty/Toys/Video Games)× 三学生结构(MLP 1.664M / GRU 1.201M / CNN 1.753M)。教师为冻结 TIGER;学生为 beam=50 约束解码。所有任务指标为全量 test 集;诊断分析在每数据集随机 10,000 请求(seed 42)上进行。
> **训练臂定义**(验证方案 §5.1):CE=真实目标交叉熵;Tok=gold-prefix token KD;F=同候选支持完整物品 KL;H=HServe 层级边缘;P=cross-cutoff pair anchor;U=均匀有效深度增量;R+=正向残差加权增量;D=DA-CDRS。
> **口径注意**:A0/A2/A5/A7/A8 为纯 CE 基座;A1/A3/A4/A6/A9 基座含 Tok。跨组对比时注意该差异。

## 1. V0:公式与实现核验

> 用 Beauty test 真实批次对 §1.1 的 8 项最小核验逐一执行。

| 编号 | 核验项 | 结果 |
|---|---|---|
| 1 | 逐位 log-prob 之和 == 完整物品分数 | PASS |
| 2a | 完整候选概率和为 1(max 偏差 1.2e-7) | PASS |
| 2b | 深度 1-3 前缀边缘和为 1(max 偏差 2.4e-7) | PASS |
| 3a | 深度增量之和 == 完整 gap | PASS |
| 3b | 分叉前增量严格为零 | PASS |
| 4 | DA 有效深度 mask = 分叉后且 d<L | PASS |
| 5 | da_cdrs_loss 在真实数据上有限(loss=0.051) | PASS |
| 6 | 教师分数 stop-grad / 学生分数保留梯度 | PASS |
| 7a | HServe(仅 d4)与 list KL 完全等价(diff=0) | PASS |
| 7b | lambda_corr=0 时 DA 项为零 | PASS |
| 8 | 学生前向独立于教师(推理不调用教师) | PASS |

## 10. 主张—证据对照

| 主张 | 证据 | 结果 |
|---|---|---|
| 局部条件拟合没有充分保持分支偏好 | H1 + 大类学错统计 | 支持(低 T 组仍 12-31% 分支偏移;大类学错 13-43%) |
| 显式前缀边缘带来额外推荐价值 | H2(A2 vs A3) | 见 H2 表(H 在多数配置≥F) |

## 11. 限制与后续

1. 全部为单种子(42)结果,稳定性需 ≥3 种子。
2. A0/A2/A5/A7/A8 为纯 CE 基座,与含 Tok 的 A1/A3/A4/A6/A9 跨组比较存在口径差异。
3. J4(在线成本分账)与 P1/P2 扩展(H3/D4/R1/R3)未做。
4. 诊断样本为每数据集 10,000 请求;D2-e 权重对比为每配置 50 万有效 pair 抽样。
