## 关键结论

1. **ServeSID 跨结构/跨数据集稳定**:三个学生、三个数据集上 NDCG@10 均为第一或并列第一。
2. **学生越弱收益越大**:CNN+ServeSID 在 Beauty/Toys/VG 上相对 base 提升 +15.4%/+18.8%/+10.4%。
3. **RCE-KD 是最强基线**,SmartGR 在 Beauty 上有效但 Toys/VG 上不稳定。
4. **LOHRec 全面垫底**。
5. **Jac(与教师一致性)方面 ServeSID 同样领先**,说明其收益来自与教师服务列表的对齐。

## 备注

- GRU/CNN 学生实际运行参数为 GRU hidden=384(1.201M)、CNN d=256(1.753M),与 MLP 1.664M 存在差距(启动脚本 DIM_ARGS 丢失所致)。如需严格参数匹配版本需重跑。
- 教师参考为 beam=20(genrec 默认),学生为 beam=50,绝对值不完全可比,仅供量级参考。
- ServeSID 消融实验(HServe only / DA-CDRS only / d4-only KL / HServe+pair / HServe+attribution-off)另存,完成后补充。
