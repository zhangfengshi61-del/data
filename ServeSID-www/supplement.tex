\section{Datasets and Evaluation Protocol}
\label{sec:sup-datasets}

We evaluate Amazon Beauty and Toys from Amazon Reviews 2014 and Video
Games from Amazon Reviews 2023 using chronological leave-one-out
next-item evaluation, with at most 20 preceding interactions per
request. Preprocessing, user/item mapping, SID assignments, and
train/validation/test splits are shared among methods within each
dataset. Processed user, item, and interaction counts are not
available in the manuscript source and are not estimated here.

\section{Implementation and Hyperparameters}
\label{sec:sup-hyper}

All methods share the same fixed TIGER teacher checkpoint, RQ-VAE
tokenizer, and four-token SID space with codebook size 256. The
three student backbones encode the last 20 interactions and score
each SID depth with lightweight heads:

\begin{itemize}
\item \textbf{MLP}: 1.664M trainable parameters;
\item \textbf{GRU}: hidden size 384, 1.201M trainable parameters;
\item \textbf{CNN}: embedding dimension 256, 1.753M trainable parameters.
\end{itemize}

\noindent\emph{Architecture comparison:} the MLP, GRU, and CNN students
have different parameter budgets, so cross-architecture scores should
not be interpreted as capacity-matched comparisons. Within each
architecture, the method comparisons use its fixed student backbone.

Students decode with constrained beam search of width $W=50$
(top-50); the TIGER teacher reference is decoded with beam 20 (the
genrec default) and is reported for scale only, since the absolute
values are not directly comparable across beam widths.

ServeSID hyperparameters: support size $M=64$, training cutoff
$K_{\mathrm{tr}}=10$, maximum outsider rank $B=40$, online beam
$W=50$, HServe weight $\lambda_H=4$, DA-CDRS weight $\lambda_D=1$,
depth weights $\alpha_d=1$ for $d=1,\dots,L$, pair margin $\mu=.05$,
increment-correction weight $\lambda_{\mathrm{corr}}=31.42$, learning
rate $5\times10^{-5}$, and author-reported seeds $\{42,43,44\}$.
The tables provide author-reported mean/SD aggregates, not the
per-seed evaluation files. For the 72 Base-KD and Full configurations
shared between the main and ablation tables, the author selected the
ablation summary as the canonical SD source; mean values were
unchanged. This reporting reconciliation does not establish
run-level statistical verification.
Teacher supports, marginals, pairs, and increment scales should be
constructed only from training requests; validation/test teacher
outputs must not enter optimization.

\section{Diagnostic Metrics and Protocol}
\label{sec:sup-diagnostics}

We evaluate diagnostics on 10,000 held-out requests per domain
using teacher-proposed top-40 valid SIDs as a common support.
For each prefix depth, preferred-prefix disagreement is the fraction
of requests where teacher and student select different groups of
maximum aggregated probability. Mixed-sign pairs have at least one
positive and one negative residual among eligible depths from the
first SID divergence through $L-1$. We also report the fractions with
at least two positive residuals and with a negative largest-magnitude
residual. The cancellation ratio summarizes cancellation between
positive and negative signed depth residuals; aggregation details, treatment of zero residuals, and tie-breaking
remain implementation-level reproducibility requirements.


\section{Cost Measurement and Parameter Sensitivity}
\label{sec:sup-cost}

and online beam width $W$. The final Full objective uses
$M=64$, $B=40$, $K_{\mathrm{tr}}=10$, and $W=50$.
A separate J4 cost audit, reported by the authors on Beauty 2014,
used a \emph{40-slot teacher candidate dump} during the training
timing probe. The following offline numbers therefore characterize
the \emph{$M=40$ cost configuration}, not a measured $M=64$ Full
run. Serving-time execution is independent of the offline teacher
support size and retains the corresponding Base student's
inference graph.

\section{Reproducibility Notes}
\label{sec:sup-repro}

\begin{itemize}
\item Evaluation: next-item utility is Recall@$K$ and NDCG@$K$ under
leave-one-out on the held-out interaction; teacher-agreement Jac@$K$
is the Jaccard between the student's beam-50 top-$K$ list and the
teacher's beam-20 top-$K$ list.
\item The base student (SID-MLP / base KD) minimizes ground-truth SID
cross-entropy plus gold-prefix token KL (Eq.~2 of the main paper).
ServeSID replaces token KL with HServe and DA-CDRS. The
complete-pair Softplus function is used only to calculate detached
DA attribution weights; no direct pairwise anchor loss is optimized.
The \emph{HServe + Plain Pair} control instead minimizes
the mean complete-candidate Softplus pair loss directly, with
coefficient $\lambda_P=1$, alongside digit CE and HServe,
using the same teacher-ordered pair support and margin.
This comparison contrasts a global pair-ranking objective against
depth-localized residual correction; the paper-aligned training
configuration gives the exact intended loss coefficients; its
checkpoint provenance still requires run-log verification.
\item Held-out diagnostic pairs (teacher ranks $1{:}K$ vs.\
$K{+}1{:}B$) are used only for mechanism statistics and never enter
optimization.
\end{itemize}
